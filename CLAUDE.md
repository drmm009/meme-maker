# Meme Creator Studio

Browser-first meme maker: React 19 + Vite 8, canvas-2D image editor, FFmpeg WASM video export, PWA, wrapped for Android with Capacitor. No backend — everything runs client-side. The gallery persists in IndexedDB (`src/utils/galleryStore.js`); settings, favorites and watermark use `localStorage` (`src/utils/storage.js`).

## Commands
- `npm run dev` — Vite dev server on http://localhost:5173
- `npm test` — Vitest (jsdom). Run after every change.
- `npm run lint` — oxlint
- `npm run build` — production build to `dist/` (also the Capacitor `webDir`)
- `npm run deploy` — publish `dist/` to GitHub Pages
- CI (`.github/workflows/ci.yml`) runs lint, test, build on every push.

## Layout
- `src/App.jsx` — top-level view switching (discovery, editor, explore, gallery, social)
- `src/components/MemeEditor.jsx` (~240 lines: wiring only; the canvas area is `editor/CanvasStage.jsx`, start-up effects `editor/hooks/useEditorSetup.js`, the selected layer `useActiveLayer.js`, toolbar auto-scroll `useToolbarAutoScroll.js`) and `CanvasEditor.jsx` (~210 lines: wiring only; plain canvas 2D; reads the editor stores) — the image editor. Under `src/components/canvas/`: `render/` (`renderScene` + one painter per layer type), `draw/` (pure drawing helpers), `interaction/` (`useCanvasInteraction` holds gesture state and calls the editor's handlers; the maths is pure and tested: `layerBoxes.js` box/handle positions, `hitTest.js`, `hoverCursor.js`, `dragMath.js` rotate/resize/crop/move+snap, `freehand.js`, `geometry.js`; plus `usePointerListeners`), `layout/` (canvas size, header/footer bands, layer centres) and `CaptionTextOverlay.jsx`. Layer x/y are 0..1 of the image area; hit tests work in canvas pixels. UI panels live in `src/components/editor/`: `top-bar/` (close, aspect ratio, undo/redo, export; same layout as the video editor), `EditorSidebar.jsx` (the bottom deck, Concept 1 "Orbit & Halo": quick chips over a trigger bar with a central "+" that opens `OrbitOverlay.jsx`, a searchable command palette plus an orbit of favourite tools, portalled into `<body>`; tools come from `hooks/useTabTools.jsx`; drawing shows a Draw Studio card; a selected layer gets a "<kind> Studio" inspector card with its `ContextToolbar` and Done), `context-toolbars/` (the selected layer's tools and the setting bars that float above the bar), `EditorModals.jsx`. The editor uses the same phone-style layout at every width; logic in `editor/hooks/` and `editor/store/`. Add new UI as panels there rather than growing MemeEditor. See `docs/plans/meme-editor-split.md`.
- Toolbar submenus are `motion.div` children of `AnimatePresence`; keep them direct children (don't wrap them in components) or exit animations break.
- `src/components/editor/store/useEditorUiStore.js` — the image editor's shared UI state (active tab/submenu, open menus and modals, brush, watermark). Not undoable. Panels read it directly; don't thread these values through props.
- `src/components/editor/hooks/use*Actions.js` — edit handlers grouped by feature (captions, layers, social cards, bubbles, canvas frame, drawing).
- `src/components/editor/store/useMemeEditorStore.js` — the image editor's document state (captions, layers, header/footer, drawings…) and undo/redo, one store per editor via React context. Call `pushHistory()` after a user edit to make it an undo step; plain setters don't record history.
- `src/components/video-editor/` — video editor; state in `src/store/useVideoEditorStore.js` (zustand + zundo undo). Always dark, phone layout at every width. `VideoEditor.jsx` is the shell: preview/edit modes, transport row, export. `timeline/` is the centre-playhead scrolling timeline (`TimelinePanel`, `TimelineClip`, pure `timelineMath.js`). `ToolRail.jsx` holds the add tools and swaps to the selected clip's tools. `AddMedia.jsx` holds every way to add media (file pickers plus the shared emoji/sticker/template bottom sheets). `CanvasPreview.jsx` is the Konva preview and sizes itself to its container. Items carry `hidden`, `muted`, `volume` (0..1) and `fadeInMs`/`fadeOutMs`; preview and FFmpeg export both respect them (`src/utils/audioFades.js`). Videos append to the end of the main sequence; `splitItem`/`duplicateItem` live in the store. Video items can carry `chromaKey` ({ color, similarity, blend }; color `'auto'` until the preview samples it): `src/utils/chromaKey.js` mirrors FFmpeg's chromakey + despill so the preview matches the export. Text items can carry `animation` ('pop' | 'shake' | 'typewriter'): `src/utils/textAnimation.js` is the shared model; the preview animates only during playback (paused text rests), and export renders stills per step, with shake done as overlay expressions. GIF stickers are `sticker` items with `isGif`: the preview decodes their frames with `ImageDecoder` (`src/utils/gif.js`) and FFmpeg reads them natively; the Giphy picker uses `src/services/giphy.js` (needs `VITE_GIPHY_API_KEY`). `exportVideoFFmpeg(..., onProgress(percent, { phase, etaSec }), { format: 'gif' | 'mp4', backgroundColor, download })` (`src/utils/ffmpegExport.js`: fetches clips, renders text stills, runs FFmpeg) renders an MP4 or palette GIF and returns `{ blob, fileName }`; the FFmpeg command itself is built by the pure, tested `src/utils/exportGraph.js`, and `ffmpegExport.test.js` snapshots the full command for typical projects against a fake FFmpeg, so update those snapshots (`npx vitest -u`) only for intended changes; the editor passes `download: false` and shows `ExportReadyCard` (share sheet or save). `cancelExport()` terminates FFmpeg mid-export. Meme effects: freeze frame (`insertFreeze`), reverse/boomerang (`applyClipEffect` swaps in an FFmpeg pre-render from `src/utils/clipEffects.js` and keeps `original`), zoom-punch (`item.punches` in footage ms, `src/utils/zoomPunch.js`). Slow jobs set the store's `busy` label and never overlap an export. Drawing order (preview and export) comes from `src/utils/layerOrder.js` (video < photo < sticker < text, overridden by `item.z` via `moveLayer`). Colour filters (`item.filter`, `src/utils/clipFilters.js`: canvas CSS filter in the preview, colorchannelmixer + lutrgb in export), transitions (`item.transitionIn` on the incoming clip, `src/utils/clipTransitions.js`), voiceovers (`src/utils/voiceRecorder.js`, audio items keep `mimeType` so export names the file right), and export `resolution` 720 or 1080. Timeline filmstrips come from `src/utils/filmstrip.js` (frames cached per URL, not stored in the project). The project auto-saves to IndexedDB (`src/utils/videoDraftStore.js`, its own `meme-creator-video` database, uploaded files stored as Blobs) and `useVideoDraft` offers to restore it. Auto captions (Text > Captions): `src/workers/whisper.worker.js` runs Whisper tiny.en (transformers.js, imported from jsDelivr at a pinned version so its ONNX WASM isn't bundled; model cached by the browser) via `src/utils/transcriber.js`; `src/utils/clipAudio.js` pulls 16 kHz mono audio from heard videos and voiceovers; `src/utils/captionChunks.js` groups words into 2-4 word captions and styles them (classic, creator, typewriter). Captions are text items with `autoCaption: true` (`setAutoCaptions`/`restyleAutoCaptions`/`removeAutoCaptions`), share one timeline row, and export as a single concat image sequence (`src/utils/captionTrack.js`) instead of one FFmpeg input each.
- `src/components/editor/` — bottom-sheet tools (stickers, emoji, filters, bubbles, template picker), each with a `.test.jsx`
- `src/data/` — static content: templates, video templates, stickers, sounds, filters, AI caption fallbacks
- `src/utils/` — face landmark/morph/graft engines, FFmpeg export, download, gallery/storage helpers
- `src/styles/theme.css` — theme tokens; `src/App.css` (~4.5k lines) holds most global styles
- `public/` — static assets served at `./` (template images, sounds, ffmpeg core, imgly models)
- `android/` — Capacitor Android project (`npx cap sync android` after a build)
- `face_swap_server.py` — optional local face-swap API on :5174, proxied at `/api/face-swap` by Vite

## Conventions
- Plain JSX (no TypeScript). Plain CSS files next to components.
- `vite.config.js` uses `base: './'` so builds work under GitHub Pages and Capacitor — keep asset paths relative.
- Heavy libs (FFmpeg, MediaPipe, background removal) load lazily at runtime; don't import them eagerly.
- Optional env: `VITE_GIPHY_API_KEY` (see `.env.example`). Gemini keys are user-supplied in-app — never hardcode keys.

## Not part of the app

- `.agents/`, `design-preview/`, `penpot-design-pack/` — design tooling and mockups, not shipped.
