# Meme Creator Studio — detailed architecture notes

> Full feature-by-feature map, moved out of CLAUDE.md to keep it short. Read the section for the area you are working on.

Browser-first meme maker: React 19 + Vite 8, canvas-2D image editor, FFmpeg WASM video export, PWA, wrapped for Android with Capacitor. No backend — everything runs client-side. The gallery persists in IndexedDB (`src/utils/galleryStore.ts`, records shaped and versioned by `src/model/galleryRecord.ts`); videos saved to My Studio live in the video editor's own database (`src/utils/videoDraftStore.ts`); settings, favorites and watermark use `localStorage` (`src/utils/storage.js`).

## Commands
- `npm run dev` — Vite dev server on http://localhost:5173
- `npm test` — Vitest (jsdom). Run after every change. Test files share a module cache (`isolate: false`), so a file that mocks a module another test file also loads calls `vi.resetModules()` and imports what it tests with `await import()`.
- `npm run lint` — oxlint
- `npm run typecheck` — TypeScript type check (`tsc`, TypeScript 7; checks `.ts`/`.tsx` files only)
- `npm run build` — production build to `dist/` (also the Capacitor `webDir`)
- `npm run deploy` — publish `dist/` to GitHub Pages
- CI (`.github/workflows/ci.yml`) runs lint, typecheck, test, build on every push.

## Layout
- `src/App.jsx` — top-level view switching (discovery, editor, explore, gallery, social). The editor's Back button returns to the view it was opened from (`editorFrom`: Home, Explore, the layout builder…), or Home when the app opened straight into a maker's link
- `src/components/home/HomeTools.tsx` — on Home (`TemplateDiscovery.jsx`), under the hero carousel: the makers as tiles, all visible at once (`homeTools.css`): Meme video, Stickers, Face swap (three across), Social card, AI meme (two across, icon beside the name). Each tile is a dark grey card in its tool's colour (its carousel slide's: cyan, mint, amber, pink, violet, as `--tone`): the icon white on a squircle of it, a faint wash of it in the top-right corner, a fine light edge and a soft shadow, and one line saying what it does. Each sends its action to `TemplateDiscovery`'s `handleFeatureClick`, as the carousel's buttons do
- `src/components/pages/pageLook.css` — the shared look of the pages outside the editors (Choose a layout, Explore, Social, My Studio), in the editors' visual language: always dark, over a warm glow like Home's but cleaner (it recolours the shell's fixed `.app-static-bg` while such a page shows: near black, the accent glowing down from the top with a touch of pink and amber, gone by mid-screen; `.pg` sits above that layer at z-index 1), cards and controls in iOS greys (`#1c1c1e`, `#2c2c2e`, `#3a3a3c`), solid orange `#ff5a36` for what's primary or picked, section headings with a plain orange icon and no circle, the faint light hairline around pictures; no gradients, glows, glass or blur. ## Conventions
- New code in TypeScript (`.ts`/`.tsx`, strict); existing `.js`/`.jsx` is converted file by file (with `git mv` so history follows). Plain CSS files next to components.
- Saved data carries a format version (gallery records, video drafts). When its shape changes, bump the version in `src/model/` and teach that model's migrate function to upgrade the previous version, so saved memes and drafts keep opening.
- `vite.config.js` uses `base: './'` so builds work under GitHub Pages and Capacitor — keep asset paths relative.
- Heavy libs (FFmpeg, MediaPipe, background removal) load lazily at runtime; don't import them eagerly.
- Optional env: `VITE_GIPHY_API_KEY` (see `.env.example`). Gemini keys are user-supplied in-app — never hardcode keys.
