# Meme Creator Studio — detailed architecture notes

> Full feature-by-feature map, moved out of CLAUDE.md to keep it short. Read the section for the area you are working on.

Browser-first meme maker: React 19 + Vite 8, canvas-2D image editor, FFmpeg WASM video export, PWA, wrapped for Android with Capacitor. No backend — everything runs client-side. The gallery persists in IndexedDB (`src/utils/galleryStore.ts`, records shaped and versioned by `src/model/galleryRecord.ts`); settings, favorites and watermark use `localStorage` (`src/utils/storage.js`).

## Commands
- `npm run dev` — Vite dev server on http://localhost:5173
- `npm test` — Vitest (jsdom). Run after every change. Test files share a module cache (`isolate: false`), so a file that mocks a module another test file also loads calls `vi.resetModules()` and imports what it tests with `await import()`.
- `npm run lint` — oxlint
- `npm run typecheck` — TypeScript type check (`tsc`, TypeScript 7; checks `.ts`/`.tsx` files only)
- `npm run build` — production build to `dist/` (also the Capacitor `webDir`)
- `npm run deploy` — publish `dist/` to GitHub Pages
- CI (`.github/workflows/ci.yml`) runs lint, typecheck, test, build on every push.

## Layout
- `src/App.jsx` — top-level view switching (discovery, editor, explore, gallery, social)
- `src/components/MemeEditor.jsx` (~240 lines: wiring only; the canvas area is `editor/CanvasStage.jsx`, start-up effects `editor/hooks/useEditorSetup.js`, the selected layer `useActiveLayer.js`, toolbar auto-scroll `useToolbarAutoScroll.js`) and `CanvasEditor.jsx` (~210 lines: wiring only; plain canvas 2D; reads the editor stores) — the image editor. Under `src/components/canvas/`: `render/` (`renderScene` + one painter per layer type; caption blur is painted without ctx.filter in `render/paintLayers.ts` via multi-pass copies for Safari compatibility), `draw/` (pure drawing helpers), `interaction/` (`useCanvasInteraction` holds gesture state and calls the editor's handlers; the maths is pure, tested TypeScript: `layerBoxes.ts` box/handle positions, `hitTest.ts`, `hoverCursor.ts`, `dragMath.ts` rotate/resize/crop/move+snap plus `keepShape` preserving photo proportions on side handles, `freehand.ts`, `geometry.ts`, `drawingHits.ts` (picking, moving and resizing shapes and censor regions), `layerPinch.ts` (two fingers on a layer, the first having gone down on it, scale and turn it, snapping to quarter turns; two fingers elsewhere zoom the view), `viewZoom.ts` (the editor's pinch-zoom and pan, a CSS transform on the canvas wrapper run by `useCanvasView`: two fingers, ctrl + wheel or a trackpad pinch zoom, one finger on empty space or the wheel pans while zoomed, a pill goes back to fit; the meme and export don't change); plus `usePointerListeners`), `media/` (GIF photos and stickers and video photos play: `animatedSources.ts` turns each into a source drawing its current frame into a canvas kept in the image cache under the layer's url, so the painters need nothing new; `useAnimatedLayers` redraws while they play, held still while drawing, and hangs `canvas.animation` (`loopsMs`, `pause`, `resume`, `seek`) on the canvas for the export), `layout/canvasLayout.ts` (canvas size, header/footer bands, layer centres) and `CaptionTextOverlay.jsx`. Layer x/y are 0..1 of the image area; hit tests work in canvas pixels. The layer types are in `src/model/memeDocument.ts`. The UI is built on the shared kit in `src/components/ui/` (TypeScript: `TopBar`, `SegmentedControl`, `ToolDock`, `ToolStrip` (a row of tool buttons above the dock), `FloatingToolbar`, `Sheet`, and `controls.tsx` for sections, rows, chips, toggles, swatches, sliders, switches and tiles; `ui.css` holds the dark tokens, applied by the `.ui-theme` class on the editor root; the video editor should move onto it too). Panels live in `src/components/editor/`: `top-bar/EditorTopBar.jsx` (back, title, undo/redo, Export), `export/` (`ExportSheet`: PNG/JPG/WebP, quality, full/720/480 width, a transparent-background switch (PNG/WebP; `exportCleanCanvas({ transparent })` leaves out the background colour), a live file-size line, Download/Share/Copy (always PNG)/Save to Gallery (full PNG with its layers); GIF and MP4 when a layer moves: `motionExport.ts` draws the meme frame by frame, seeking every moving layer through `canvas.animation`, and encodes with WebCodecs (MP4) or FFmpeg (palette GIF at most 480 px, or MP4 without WebCodecs), one loop of the longest layer, 1-15 s, MP4s at least 3 s, no sound; the choices persist as `exportPrefs` in the UI store; the pure, tested `exportImage.ts` scales and encodes `canvas.exportCleanCanvas()`, the meme without selection handles, from render/renderScene), and `panels/`: `AspectBar` (aspect pill over the canvas, gone while a sheet is open), `EditorPanels` (the dock of five tabs, Draw, Media, Text, AI/Filters and Canvas, the open one a wide gradient pill; every tab shows a `ToolStrip` of its tools above the dock, and a tool acts straight away, opens an existing studio, or opens a sheet under the strip: Draw: Brush/Glow/Marker/Eraser/Shapes/Censor turn drawing on (the eraser rubs out drawing only: render/paintDrawings puts the ink on a layer of its own when there is an eraser stroke, and the live stroke redraws the scene through `onPreviewStroke`) and open `DrawSheet` (colour and size; the shape, width and fill; the censor style and strength; clear), drawing stays on until Draw is tapped again. Shapes (arrow, circle, box, line, sketch ring, highlight box, both-ways arrow) and censor regions (blur, pixelate, black bar) are dragged out on the canvas and saved in `drawings` as `{ type: 'shape' | 'censor', points: [start, end] }`; a new one is selected (its id is the `activeLayerId`) and can be moved or resized by its ends/corners, picked again by tapping it (or pressing it while drawing that kind); its floating toolbar has Style (the Draw sheet, which then edits the selected one), Copy and Delete; `canvas/draw/shapes.ts` paints them (censor without ctx.filter, so iOS matches) for the canvas, the export and the tests; Media (`MediaStrip`): Photo (file picker), then Templates, Stickers, GIFs (Giphy, added as a sticker that plays) and Emoji, each a sheet docked under the strip in the Draw sheet's style (`panels/MediaPickerSheet.tsx`: category tiles, search, a grid that scrolls on its own; `TemplatesSheet`, `StickersSheet`, `GifSheet`, `EmojiSheet`; a pick adds the layer and closes the sheet; the filters are in `panels/mediaPickers.ts`, shared with the video editor's pop-up pickers), Link (`panels/LinkSheet.tsx` to add from web URLs; pictures can also be dropped onto the canvas or pasted from clipboard, handled by `utils/imageFromLink.ts` and `editor/hooks/useMediaInput.js`), and `MediaSheet` for a selected image or sticker, opened from its floating toolbar: for a photo (More) a compact sheet, a row of five tiles (Mirror, Flip upside down, Copy, Replace swapping the picture in place, Face Swap) and sliders for opacity, rounded corners, border and shadow (crop, filters, cut out, layers and delete are on the floating bar; `keepShape` and blend modes are no longer offered for photos); for a sticker `StickerControls` (chips show custom `layerName` when set) and `LayerLookControls` (upside down, opacity, blend mode, shadow); the look is painted with `canvas/draw/layerLook.ts`, a framed photo drawn on a canvas of its own first so its shadow follows it; Text (`TextStrip`): Add Text, Edit (`TextSheet`, with `CardControls` for social cards), Bubble (adds a bubble caption and opens `BubbleSheet`, the chat and speech styles from `panels/bubblePresets.ts` in the picker layout), Social Card; AI/Filters (`AiFiltersStrip`): Face Swap and AI Caption open their studios, Remove BG works straight away, Filters opens `FiltersSheet` (presets for the selected image, else the meme; folded-away Adjustments: brightness, contrast, saturation and, from `canvas/draw/photoEffects.ts` without ctx.filter, warmth, sharpen and vignette, for the photo, the whole meme or the selected image; Portrait background blur cuts the photo's subject out once with the background-removal model, kept in `imageFilters.subjectUrl`/`subjectOf`, and draws it sharp over a blurred copy); Canvas (`CanvasStrip`): Canvas Style and Watermark open `CanvasColorSheet` (Mirror flips the whole meme; Crop, when the meme has a main photo; solid colours or two-colour diagonal gradients via `canvasBgGradient` in the store and draft) and `WatermarkSheet`, Header and Footer switch straight away; Crop opens `editor/crop/PhotoCropSheet` (box, aspect, quarter turns; `cropMath.ts` bakes a new main photo, an undo step, keeping `uncroppedUrl`) (`hooks/usePhotoActions.js`; a new main photo drops the template's stored width/height so the canvas takes its shape). The UI store keeps `dockTab` and `sheet`: `openSheet(sheet, focus)` also shows the sheet's tab strip, `showDockTab` / `pickDrawTool` / `leaveDock`; `FaceSwapSheet` while a template face swap is tuned), `LayersSheet` (every layer topmost first, from `layerRows.ts`, and shapes/censor regions in their own list: custom `layerName` with inline rename button, select, move up/down, hide, lock; Select mode ticks several to align or spread out (pure `arrange.ts` on the boxes the painters report in `canvas.layerBoxes`, one layer aligning to `canvas.imageArea`; `hooks/useArrangeActions.js`), group (`groupId`: dragging one moves its group), ungroup or delete; opened from the Layers button every floating toolbar has), and `LayerToolbar`, the selected layer's quick tools as a floating pill just above the dock, in place of the tab's tool strip while a layer is selected (not while drawing; EditorPanels swaps them; the pill scrolls sideways when its tools don't fit; no dock tab is lit meanwhile, and tapping any dock tab deselects the layer and shows that tab's strip). A sheet opened from the pill (`openSheet(sheet, focus, true)` sets `sheetFromPill`) keeps the pill above it with that tool lit, tapping it again closes the sheet, and selecting another layer closes it. A caption's bar has Font (fonts and My styles), Style (three rows without headings: bold/italic/underline/case boxes, a size slider, effects), Align (alignment, letter and line spacing), Color (compact rows: solid colours then gradients on one sideways line, outline switch and thickness with its colours under it, shadow with its colours once on) and Box (the box behind the text, opacity), plus Bubble on a bubble, Layers and Delete; each opens `TextSheet` with just its sections (`openSheet('text', part)`; `SECTIONS` maps every section to its part); the strip's Edit opens all of them together, with the layer actions. The open sheet is `sheet` in the UI store (`openSheet(sheet, focus)` / `closeSheet()`); selecting another kind of layer switches it. The edit handlers reach the panels as one `actions` object built in MemeEditor (`panels/selection.ts`). Captions may be `bold: false`, `italic` or `underline`, may shrink to fit (`autoFit`, `maxLines`, kept for saved memes though the Text sheet no longer offers it; `fittedFontSize` in captionFont.ts, used by painting, hit boxes and band heights), and carry `letterSpacing` (em), `lineHeight`, `shadowSize`/`shadowColor`, a dedicated outline colour swatch row (`stroke`), and a two-colour `gradient` (`canvas/draw/captionFont.ts`: `applyCaptionFont` sets the font and spacing for measuring and drawing alike; `withIndicFallback` and `ensureIndicFonts` support Hindi and Gujarati fonts with bold weights and glyph fallbacks). Fonts are the Google Fonts in `index.html` (listed in `data/stickers.js` `FONTS`) plus fonts the user uploads (`src/utils/customFonts.ts`: kept in IndexedDB `meme-creator-fonts`, registered with FontFace; `editor/hooks/useCustomFonts.ts` loads them). The Text sheet's My styles saves a caption's look to localStorage (`src/utils/textStyles.ts`) to put on others. The top bar's History button opens `editor/library/LibrarySheet` (History: every undo step, labelled by `historyTimeline.ts`, tap to jump; My memes: save the meme as a project or a template to the `projects` store of the `meme-creator-image` database (`memeDraftStore.ts`, DB version 2) and open one as a fresh session like a restored draft, via `hooks/useProjects.js`; Shortcuts: keyboard shortcuts list from `editor/library/shortcutsList.ts` in small `<kbd>` boxes with a `forMac` helper, also opened by pressing `?` via `libraryTab` in `useEditorUiStore.js`). A first-run tour (`panels/FirstRunTour.tsx`, placement in `tourPlacement.ts`) walks through the dock, canvas, shape and Export once (`meme-maker-editor-tour-v1` in localStorage). Every docked sheet shares the Draw sheet's look (`panels.css`, scoped to `.ie-panels--sheet`: compact rows, small muted section labels, kit tiles as one scrolling line or sharing the width, segmented choices as tile boxes, an orange outline for what's on); sheets opened from a strip button pass `hideTitle` to `ui/Sheet` (the strip shows what's open), while Layers, Export, History & saved and Face Swap keep their titles. The photo cropper and the studios (AI caption, social cards, face swap) live in `EditorModals.jsx`. The editor uses the same phone-style layout at every width; logic in `editor/hooks/` and `editor/store/`. Add new UI as panels there rather than growing MemeEditor. See `docs/plans/meme-editor-split.md`.
- `src/components/editor/store/useEditorUiStore.js` — the image editor's shared UI state (open sheet, open modals, brush, watermark). Not undoable. Panels read it directly; don't thread these values through props.
- `src/components/editor/hooks/use*Actions.js` — edit handlers grouped by feature (captions, layers, social cards, bubbles, canvas frame, drawing).
- `src/components/editor/store/useMemeEditorStore.js` — the image editor's document state (captions, layers, header/footer, drawings…) and undo/redo, one store per editor via React context. Call `pushHistory()` after a user edit to make it an undo step; plain setters don't record history. The meme auto-saves after each edit (once there is an undo step) to IndexedDB (`src/utils/memeDraftStore.ts`, its own `meme-creator-image` database, blob: pictures stored as Blobs, versioned by `MEME_DRAFT_VERSION`); `editor/hooks/useMemeDraft.ts` shows the `DraftOffer` banner, and restoring starts a fresh editor session on the draft's template and document.
- `src/components/video-editor/` — video editor; state in `src/store/useVideoEditorStore.js` (zustand + zundo undo). Always dark, phone layout at every width. `VideoEditor.jsx` is the shell: preview/edit modes, transport row, export. `timeline/` is the centre-playhead scrolling timeline (`TimelinePanel`, `TimelineClip`, pure `timelineMath.js`). `ToolRail.jsx` holds the add tools and swaps to the selected clip's tools. `AddMedia.jsx` holds every way to add media (file pickers plus the shared emoji/sticker/template bottom sheets). `CanvasPreview.jsx` is the Konva preview and sizes itself to its container; its parts are in `preview/` (`CanvasMedia`, `CanvasText`, `GridOverlay`; `previewVideo.js` keeps each clip's hidden `<video>` in step with the playhead; hooks for green screen/filters, GIF frames, text playback, stage fit and in-place text editing), and its decisions are pure and tested in `preview/previewMath.ts` and `nodeMotion.ts`. Preview and export share what they draw: text from `src/utils/textLayer.ts` (`textAttrs`/`textBoxAttrs`; the export draws its text stills with them at output scale), rotation from `src/utils/rotation.ts` (clips turn about their top-left corner like Konva; Rotate turns about the centre; the export rotates with FFmpeg into the same place), and the layout grid lines from `src/utils/gridLines.ts`. Clip and project types are in `src/model/videoProject.ts`. Items carry `hidden`, `muted`, `volume` (0..1) and `fadeInMs`/`fadeOutMs`; preview and FFmpeg export both respect them (`src/utils/audioFades.ts`). Videos append to the end of the main sequence; `splitItem`/`duplicateItem` live in the store. Video items can carry `chromaKey` ({ color, similarity, blend }; color `'auto'` until the preview samples it): `src/utils/chromaKey.js` mirrors FFmpeg's chromakey + despill so the preview matches the export. Text items can carry `animation` ('pop' | 'shake' | 'typewriter'): `src/utils/textAnimation.ts` is the shared model; the preview animates only during playback (paused text rests), and export renders stills per step, with shake done as overlay expressions. GIF stickers are `sticker` items with `isGif`: the preview decodes their frames with `ImageDecoder` (`src/utils/gif.js`) and FFmpeg reads them natively; the Giphy picker uses `src/services/giphy.js` (needs `VITE_GIPHY_API_KEY`). `exportVideoFFmpeg(..., onProgress(percent, { phase, etaSec }), { format: 'gif' | 'mp4', backgroundColor, download })` (`src/utils/ffmpegExport.js`) renders an MP4 or palette GIF and returns `{ blob, fileName }`. MP4s are drawn frame by frame by the preview's own scene (`preview/sceneRenderer.ts`: the same Konva nodes and shared helpers as CanvasPreview, seeking each video per frame) and encoded by the browser at 30fps (`src/utils/webCodecsExport.ts`, WebCodecs through Mediabunny, loaded only when exporting); FFmpeg then only mixes the sound onto the copied picture (`createExportGraph({ encodedVideo })`), and isn't loaded at all for silent projects. GIFs, browsers that can't encode the size, and any failure part-way (not a cancel) use the whole-FFmpeg render instead (`encoder: 'ffmpeg'` forces it); the FFmpeg command itself is built by the pure, tested `src/utils/exportGraph.ts`, and `ffmpegExport.test.js` snapshots the full command for typical projects against a fake FFmpeg, so update those snapshots (`npx vitest -u`) only for intended changes; the editor passes `download: false` and shows `ExportReadyCard` (share sheet or save). `cancelExport()` terminates FFmpeg mid-export. Run every FFmpeg command through `runFFmpeg(ff, args)`: when the engine aborts ("Aborted()" with no return within 1.5 s; the core also prints it as every command exits normally) or a command prints nothing for a minute it terminates that FFmpeg and throws `FFmpegCrashedError`, the next `loadFFmpeg()` makes a fresh one, and the whole-FFmpeg export retries once. Meme effects: freeze frame (`insertFreeze`), reverse/boomerang (`applyClipEffect` swaps in an FFmpeg pre-render from `src/utils/clipEffects.js` and keeps `original`), zoom-punch (`item.punches` in footage ms, `src/utils/zoomPunch.ts`). Slow jobs set the store's `busy` label and never overlap an export. Drawing order (preview and export) comes from `src/utils/layerOrder.ts` (video < photo < sticker < text, overridden by `item.z` via `moveLayer`). Colour filters (`item.filter`, `src/utils/clipFilters.ts`: canvas CSS filter in the preview, colorchannelmixer + lutrgb in export), transitions (`item.transitionIn` on the incoming clip, `src/utils/clipTransitions.ts`), voiceovers (`src/utils/voiceRecorder.js`, audio items keep `mimeType` so export names the file right), and export `resolution` 720 or 1080. Timeline filmstrips come from `src/utils/filmstrip.js` (frames cached per URL, not stored in the project). The project auto-saves to IndexedDB (`src/utils/videoDraftStore.ts`, its own `meme-creator-video` database, uploaded files stored as Blobs; drafts carry `VIDEO_PROJECT_VERSION` and are upgraded by `migrateVideoProject` on load) and `useVideoDraft` offers to restore it. Auto captions (Text > Captions): `src/workers/whisper.worker.js` runs Whisper tiny.en (transformers.js, imported from jsDelivr at a pinned version so its ONNX WASM isn't bundled; model cached by the browser) via `src/utils/transcriber.js`; `src/utils/clipAudio.js` pulls 16 kHz mono audio from heard videos and voiceovers; `src/utils/captionChunks.js` groups words into 2-4 word captions and styles them (classic, creator, typewriter). Captions are text items with `autoCaption: true` (`setAutoCaptions`/`restyleAutoCaptions`/`removeAutoCaptions`), share one timeline row, and export as a single concat image sequence (`src/utils/captionTrack.ts`) instead of one FFmpeg input each.
- `src/components/editor/` — bottom-sheet pickers (stickers, emoji, bubbles, template picker), each with a `.test.jsx`
- `src/model/` — TypeScript types for the saved data: `videoProject.ts` (clips, projects), `memeDocument.ts` (image editor layers), `galleryRecord.ts` (gallery records), each with its format version and migrate function
- `src/data/` — static content: templates, video templates, stickers, sounds, filters, AI caption fallbacks
- `src/utils/` — face landmark/morph/graft engines, FFmpeg export, download, gallery/storage helpers
- `src/styles/theme.css` — theme tokens; `src/App.css` (~4.5k lines) holds most global styles
- `public/` — static assets served at `./` (template images, sounds, ffmpeg core, imgly models)
- `android/` — Capacitor Android project (`npx cap sync android` after a build)
- `face_swap_server.py` — optional local face-swap API on :5174, proxied at `/api/face-swap` by Vite

## Conventions
- New code in TypeScript (`.ts`/`.tsx`, strict); existing `.js`/`.jsx` is converted file by file (with `git mv` so history follows). Plain CSS files next to components.
- Saved data carries a format version (gallery records, video drafts). When its shape changes, bump the version in `src/model/` and teach that model's migrate function to upgrade the previous version, so saved memes and drafts keep opening.
- `vite.config.js` uses `base: './'` so builds work under GitHub Pages and Capacitor — keep asset paths relative.
- Heavy libs (FFmpeg, MediaPipe, background removal) load lazily at runtime; don't import them eagerly.
- Optional env: `VITE_GIPHY_API_KEY` (see `.env.example`). Gemini keys are user-supplied in-app — never hardcode keys.
